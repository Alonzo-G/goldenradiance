## 第一部分 · 深度研究核心结论

### 1.1 市场判断：这个赛道在卷什么

我们调研了 Nihaojewelry（80 万 SKU / No MOQ / DDP 包税）、JewelryBund、Yeajewel、Xuping 系等直接竞品，以及 Alibaba、Made-in-China、GlobalSources、Faire、FashionGo、JOOR 等平台。

结论很直接：**所有中国系饰品 B2B 站都在同一个三角里内卷 —— SKU 数量、价格、MOQ。** 没有人往外走。

### 1.2 市场空白点：规格透明化

存在一个几乎无人占领的位置：**没有任何一家把「基材牌号 / 镀层方式与厚度 / 镍释放检测值 / 可核验的报告编号」做成产品页的标准字段。**

而恰恰 buyers 的不信任已经在升级：

| 事实 | 来源 |
|---|---|
| 2025 年 11 月国内抽检 21 件低价饰品，**17 件镀层厚度不达标**；某"镀金"手镯金层 0.03μm vs 国标 0.5μm，差 16 倍 | 国内抽检报道 |
| 标 S925 耳钉**镉超标 9000 余倍** | 同上 |
| **400 元人民币即可买到虚假 CNAS/CMA 报告** | 新华社 / 央视 |

由此得出一个关键推论：**老外对中国供应商的不信任，已经从「有没有检测报告」升级到「报告能不能核」。**

这对你是好消息 —— 因为做规格透明化**不需要自有工厂**，只需要你肯把数据摊开给买家看。这是你这种贸易商身份成本最低、最快的突围路径。

**一句话定位：** 在你开口问之前，规格表已经给到你了。

### 1.3 目标市场分层（你选了「全球通吃」，这里是收敛后的答案）

你原本选了"全球通吃、按品类分层"。研究后我们**不建议真的全球通吃** —— 那会稀释 SEO 权重，等于任何词都排不上去。收敛为**按产品线主攻不同市场**：

| 产品线 | 主攻市场 | 决策驱动 | 关键要求 |
|---|---|---|---|
| **时尚合金 / 铜饰** | 中东（主）→ 拉美、非洲、东南亚 | 金色重工 + 价格敏感 | 中东要求厚金 PVD **0.3–0.5μm**，其他市场仅 0.1–0.2μm |
| **不锈钢 / 钛钢** | 北美、西欧英国（主）→ 东南亚 | 合规驱动 + 防水驱动 | 316L 低镍释放；热带市场 304 数周变色，必须上 316L |
| **天然石 / 人造宝石 / 珍珠** | 日韩澳洲（主）→ 欧美买手店 | 设计驱动 | 天然非标不怕撞款，这是差异化优势 |

**结论：V1 只做 2 个区域落地页**（中东、欧盟/英国），其余市场用 Blog 长尾内容覆盖。V1 全站英文，统一美式拼写 `jewelry`（用英式 `jewellery` 会漏掉大部分搜索量）。

### 1.4 必须知道的合规红线

这些是海外采购**必问**的，不懂会在第一轮沟通就出局：

- **EU REACH 镍释放**：限值 0.5 µg/cm²/week，**耳针类更严，为 0.2**
- **EN 1811**（无镀层）vs **EN 12472**（有镀层，模拟磨损）—— **后者买家最不懂、也最该被教育**，是天然的内容选题
- 铅 ≤ 0.05%，镉 ≤ 0.01%
- US CPSIA 100ppm、CA Prop 65、ASTM F2999 / F2923
- HS 编码 7117.19.55

**红线：不得做全站一刀切的"合格声明"。** 检测结果随批次变化，必须写成"报告按批次随报价提供"。你现在没有报告，我们就这么写。

## 第二部分 · 网站方案

### 2.1 核心视觉决策：不是画册，也不是目录，是「编辑感目录」

这是本项目最重要的一个设计判断。

调研数据显示：**78% 的批发买家进站前已经知道要买什么**，最痛的是隐藏 MOQ / 价格 / 交期；**80% 用手机做调研**，多数资深买家偏好列表视图下单（像看电子表格）。

所以我们**按页面双层分寄存器**：

| 层级 | 页面范围 | 信息密度 | 逻辑 |
|---|---|---|---|
| **Product 寄存器** | 产品中心、搜索、产品详情页、RFQ 询价篮 | 密度 7（高） | 满满是弹药：规格表、等宽数字、列表/网格双视图、MOQ/价格区间/交期/现货/认证五类信息全公开 |
| **Brand 寄存器** | 首页、三条产品线落地页、合作产线页、合规中心 | 密度 3（低） | 靠统一质感的实拍 + 克制配色 + 真负空间，建立"专业感" |

**为什么不能二选一**：你做成纯目录，3 秒被判定为"倒货中间商"；做成画册式 SKU，把 MOQ 和价格挤走，直接掉转化。

### 2.2 配色与字体

| 用途 | 值 | 依据 |
|---|---|---|
| 页面底色 | `#F7F8F9` | 冷调 off-white，刻意拒绝米色/奶油那条 AI 默认色带 |
| 身份主色 | `#123A38` | 深墨玉绿，取自珠宝绒布托盘，是世纪惯例不是流行趋势 |
| CTA 唯一强调色 | `#7D6330` | 氧化黄铜 |
| 正文 | `#14181C` | 对比度 16.8:1 |
| 产品图底 | `#FBFCFC` | 不用纯白，为了让金属/天然石更跳 |

字体：标题 **Archivo**（拒绝 Playfair 那套编辑风默认）｜正文 **Public Sans**（原生等宽数字，14px 表格可读）｜SKU 与价格 **JetBrains Mono**｜中文后台 **HarmonyOS Sans SC**（仅后台加载，前台英文站绝不加载中文包体，否则 1MB+ 直接毁首屏）。

图标锁定 **Lucide**（1700+ 图标、24px 画布 2px 描边统一、ISC 可商用、构建期内联零运行时 JS）。**全站 0 个 emoji。**

### 2.3 网站布局（V1 共 15 个页面）

```
/                                          首页
├── /product-lines/fashion-alloy-brass/    产品线 · 时尚合金铜饰（中东重工向）
├── /product-lines/stainless-titanium-steel/  产品线 · 不锈钢钛钢（欧美合规向）
├── /product-lines/natural-stone-gemstone-pearl/  产品线 · 天然石宝石珍珠（日韩设计向）
├── /products/                            产品中心（多维筛选 + 双视图）
├── /products/{sku}/                      产品详情页（八字段规格表）
├── /rfq/                                 RFQ 询价篮
├── /sourcing-partners/                   合作产线与质控（替代"工厂实力"页）
├── /compliance/                          合规与检测中心
│   └── /compliance/nickel-release-en-1811/   镍释放 EN 1811/12472 专题
├── /samples/                             样品政策
├── /shipping-payment/                    物流与付款条款
├── /faq/                                 常见问题
├── /blog/                                内容中心（SEO 长尾主战场）
└── /contact/                             联系我们
```

**首页信息架构**（从上到下）：三条产品线真实竖切 Hero → 五项信任条 → 产品线入口 → 规格透明化主张（差异化核心）→ 合规教育入口 → 最新内容 → RFQ 入口 → Footer。

### 2.4 RFQ 询价篮：转化核心

**不做独立购物车页**。三层结构：Header 计数徽标 + 右侧抽屉（420px）+ 移动端底部 sticky bar。

关键设计：
- 步进数量**按 MOQ 自动取整**
- 支持 `Paste SKU codes` 批量粘贴（V1 做；`Upload CSV` 降至 v2）
- localStorage 持久化 7 天，**未登录可用是硬要求**（买家登录墙会杀死转化）
- 空状态给三个真入口：Browse / Paste SKU codes / Upload CSV

### 2.5 技术路线

| 层 | 选型 | 版本 |
|---|---|---|
| 框架 | **Astro**（静态优先） | 7.3.5 |
| 样式 | Tailwind | 4.3.3 |
| 部署 | Cloudflare Pages + Workers | adapter 14.3.3 |
| 搜索 | Pagefind（静态索引） | 1.5.2 |
| 邮件 | Resend | 6.31.0 |
| 询价状态 | Nanostores persistent | 1.3.5 |
| 图标 | Lucide via astro-icon | iconify-json 1.2.138 |

**选型对比（加权总分）**：Astro **4.65** > Nuxt/SvelteKit 4.05 > Next 16 **3.55** > WordPress+WooCommerce 3.05 > Shopify B2B 2.95

**为什么否决 Next.js**：①为 1 个 RFQ 接口背负整个 Node 运行时，不划算；②2026-09 安全公告中 CVE 专打自托管 SSG/ISR，正命中"低成本自托管"画像；③图片优化器存在 SSRF 漏洞。

**为什么否决 Shopify**：强制 `/collections/`、`/products/` 前缀，无法兑现上面那套 `/product-lines/` 分层 SEO 路由结构 —— 而这套路由本身就是排名资产。

**后端极简**：全站只有 3 个 API（`POST /rfq`、`POST /newsletter`、`GET /health`）。**产品不落数据库** —— 它是构建期内容，落库等于多层复杂度，是典型过度设计。

### 2.6 三条必须提前知道的约束

| 编号 | 约束 | 说明 |
|---|---|---|
| **W-1** | **内容更新有 3–8 分钟构建延迟** | 不是 WordPress 那种"点保存即生效"。改价格、改文案、上新品都要走构建。**这是最容易引起误会的一点，务必有心理预期。** |
| **W-2** | 构建时长随 SKU × 图片数线性增长 | V1 首批建议 **≤300 SKU / 约 1800 张图**，构建约 2 分钟 |
| **W-5** | Cloudflare Workers 免费额度 10 万请求/日 | **超限静默返回 429** —— 也就是买家提交询盘会失败但页面显示成功。必须配用量告警，这是最危险的吞询盘故障模式 |

## 第三部分 · 实现路线选择

三条路线，请勾选其中一条。

### 路线 A · 全站一次到位（推荐）

上线 V1 全部 15 个页面 + 首批 ≤300 SKU。

- **优点**：SEO 结构完整，三条产品线 + 合规内容资产一次性铺好，起量最快
- **代价**：工期最长；你需要一次性备齐所有文案素材
- **适合**：确定这是长期主业赛道，愿意前期投入换后期省心

### 路线 B · 核心转化优先（两周速上）

只做 **8 个页面**：首页 + 三条产品线 + 产品中心 + 产品详情页 + RFQ + 联系我们。合规页、样品政策、物流条款、Blog 全部推到第二批。

- **优点**：最快跑通"曝光 → 询盘"闭环，拿到真实询盘反馈再迭代
- **代价**：初期 SEO 内容资产薄弱，第一波自然流量要等第二批
- **适合**：想先验证询盘转化率，再决定是否追加投入

### 路线 C · 内容先行（SEO 长线）

先做合规教育内容中心 + Blog 种子文章 + 首页，产品中心精简。

- **优点**：直接打"REACH compliant / EN 1811 / how to verify plating thickness"这类**低竞争高意图**长尾词，自然流量天花板最高
- **代价**：短期询盘转化弱，因为产品线展示不完整
- **适合**：不着急、想把站做成长期行业内容资产

### 三路线对比

| | 路线 A 全站 | 路线 B 核心转化 | 路线 C 内容先行 |
|---|---|---|---|
| 上线页面数 | 15 | 8 | 6 + 内容中心 |
| 首批周期 | 最长 | 最短 | 中 |
| SEO 结构完整度 | 完整 | 弱 | 强 |
| 短期询盘能力 | 强 | **最强** | 弱 |
| 长期自然流量 | 强 | 中 | **最强** |

## 第四部分 · 需要你提供的素材（拿到才开工）

以下数字**在拿到之前一律不出现在页面上** —— 编造数据是外贸站自杀的最快方式。

### P0 阻塞项（缺了动不了工）

| # | 素材 | 说明 |
|---|---|---|
| 1 | **产品名称 / Logo / Slogan** | 中英文名 |
| 2 | **首批上线产品资料** | ≤300 SKU：SKU 编号、标题、材质、电镀方式、尺寸、MOQ、参考价格区间 |
| 3 | **产品实拍图** | 你已有几百款。需按规范过一遍：去背干净、同一光位、**供应商公开图一律弃用**（撞图风险） |
| 4 | **三大产品线各自的 SKU 分布** | 决定三条产品线的页面权重分配 |

### P1 重要项（有降级写法，可后补）

| # | 素材 | 降级写法 |
|---|---|---|
| 5 | 阶梯价档位 | 先只给参考区间，精确阶梯价进入报价环节 |
| 6 | 真实交期 | `Lead time confirmed with your RFQ` |
| 7 | 首响时长承诺 | 建议承诺 **8 个中国工作小时内** |
| 8 | 覆盖国家 / 物流承运商 | `Ships worldwide` |
| 9 | 样品政策 | 建议：**样品费全额抵首单**（这是风险逆转，对标 Faire 的首单免费退货） |
| 10 | 合作产线介绍 | 取代"工厂实力"页 —— 诚实写"我们是贸易伙伴 + 合作产线分工 + AQL 验货流程" |
| 11 | 付款方式 | T/T、L/C、PayPal、西联等 |

## 第五部分 · 后续建议（非 V1 交付物）

### 检测补做优先级

PM 的建议：**先花 5,000–8,000 元，只做不锈钢/钛钢线 3–5 款的镍释放 + 铅镉**，性价比最高。

理由：这个品类在欧美本身就是合规驱动，做了立刻能用。产品线铺满检测没必要 —— 写"每份报价随附批次报告"就够了。

优先级顺序：**镍释放 EN 1811（无镀层）/ EN 12472（有镀层）> 铅镉含量 > CPSIA**
