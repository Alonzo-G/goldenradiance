## 一、已修复（9 项）

### 性能

**P1-1 静态资源缓存头全覆盖（`public/_headers` 重写）**
- 修复前实测（线上 curl -I）：**所有资源 `Cache-Control: public, max-age=0, must-revalidate`**——663MB 产品实拍 + 49MB og 图 + 字体，每次访问都要重新验证。`_headers` 此前只覆盖 `*.png`。
- 修复后：`*.webp` / `*.jpg` / `*.png` / `*.woff2` → 1 年 immutable；`/_astro/*` 1 年；`/pagefind/*`、`/sitemap*.xml`、`*.webmanifest` → 1 天；`*.svg` 30 天。
- 两个设计约束（写进文件注释，防后人踩）：
  1. 缓存规则**按扩展名收窄**。`/products/*` 会连 PDP 的 `index.html` 一起命中（Workers assets 用目录 URL 提供 HTML），给 HTML 打 immutable = 内容更新一年不可见。
  2. 每个块**自带完整安全头**。不依赖 Cloudflare「多规则合并 vs 最具体者胜」的语义细节，两种策略下安全头都完整。

**P1-2 字体自托管，Google Fonts 下线**
- 原状：BaseLayout preconnect + css2 API 外链三族字体（Archivo / Public Sans / JetBrains Mono），配 `media="print" onload` 异步 hack。
- 问题：① GDPR——访客 IP/UA 送往 Google（LG München I 2022 判例认定未同意嵌入即违法，本站主打欧盟/英国市场）；② 跨域 DNS+TLS；③ 中国区买家被墙即字体丢字。
- 修复：`scripts/fetch-fonts.mjs` 抓 latin 子集 8 个 woff2（243KB）→ `public/fonts/`，`@font-face` 进 `global.css`，异步 hack 与 noscript 兜底一并移除。改字体改脚本 `FAMILIES` 重跑即可（幂等）。

**P1-3 回归工具链可复现**
- 发现：回归脚本依赖的 playwright 是 extraneous 包（从未进 package.json），`npm audit fix` 一轮剪掉，7 个回归脚本集体不可跑——全新 clone 同样跑不了。
- 修复：playwright 1.64.0 补为正式 devDependency；新增 `npm run verify`（聚合 7 个回归脚本）；CI 设 `PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD=1`（只构建不跑浏览器，省 2-4 分钟）。

### 安全

**S1-1 邮件 HTML 注入修复（`src/lib/server/mail.ts`）**
- 内部通知邮件按 HTML 渲染，买家输入（公司/姓名/邮箱/留言/备注/SKU note）**原样字符串插值**——询盘者可往销售邮箱注入任意标记（伪造链接/按钮即钓鱼面）。qty 虽经 Zod int 校验仍一并转义（纵深防御）。
- 修复：`escapeHtml()` 全量过一遍用户输入；新增黑盒测试（stub fetch 捕获 Resend 实际请求体，断言 `<script>` 变 `&lt;script&gt;`）。

**S1-2 生产占位符修复（`src/pages/api/v1/rfq.ts`）**

- 说明：这些包只参与本地开发与构建，不在部署产物内；清零属卫生治理，非线上热修。

### 结构 / 可维护性

**M1-1 线名映射收口（5 处 → 单一入口）**
- Header / Footer / 404 / products-index / HomeLines 各自维护本地 `LINE_LABEL` 表（历史累计 8 处散点）。新增或改名一条线要同步改 8 处，漏一处就是「菜单显示 A 线、页脚显示 B 线」。

- 依据：询盘表单收集公司/姓名/邮箱/国家/WhatsApp 等个人数据、newsletter 收集邮箱，而站点明确面向欧盟/英国买家——GDPR 告知义务不能靠表单旁一句话兜底。

## 三、待决策 / 后续（本轮未动，按优先级）

1. **CSP 响应头**（RUNBOOK §12 跟踪）——阻塞点：站内 JSON-LD 为 inline script、Turnstile 需 `challenges.cloudflare.com` 放行、组件有内联 style。方案：JSON-LD 改构建期算 hash、style-src 收紧到 nonce。Google Fonts 下线后外部例外已少一个。**建议下一轮做。**
2. **网站分析**——Cloudflare Web Analytics（无 cookie、无需同意横幅、不碰 GDPR）。需 Dashboard → Web Analytics → 添加站点 → 把 beacon token 贴进 BaseLayout（一行 script）。**需要你操作 dashboard，我备好接入点。**
3. **WAF 层限流**——账户级 Rate Limiting Rule，无代码。内存限流「每 isolate 5 次/10 分钟」的局限已在 `ratelimit.ts` 注释声明，生产可接受但 WAF 规则能补全局面。
4. **后台双因素**——当前单密码 + HMAC session（8h）。TOTP 二次验证可加固，需前端+API 联动改动。
5. **Terms of Sale**——B2B 通常在报价/合同阶段约定，网站层非必需；如要可补一页。
6. **多语言**——RFQ schema 已有 `zh` 枚举，站点当前 en-only，`hreflang` 已留 x-default 位。中文站是独立工程决策，不建议顺手做。
